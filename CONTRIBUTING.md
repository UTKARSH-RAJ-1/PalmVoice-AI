# Contributing

Thanks for helping improve PalmVoice AI.

## Local workflow

1. Create a Python 3.11 virtual environment inside `sign-translator/.venv`.
2. Install `sign-translator/requirements.txt`.
3. Make focused changes that preserve the existing sign-to-text and text-to-sign demos.
4. Run the relevant demo or script locally.
5. Keep generated caches, virtual environments, credentials, and personal avatar files out of commits.

## Pull requests

Pull requests should include:

- A concise description of the user-visible change.
- Setup or documentation updates when behavior changes.
- Manual verification steps, including any hardware requirements.
- Notes about model, dataset, or asset licensing when adding them.

Please do not commit webcam recordings, microphone captures, private credentials, or unlicensed avatar/model files.
