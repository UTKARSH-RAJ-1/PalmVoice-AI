Project flow

From text to sign.

The project follows a working fingerspelling MVP for sign-to-text recognition, plus a browser-based text-to-sign demo.

01

Text input

Text is currently converted to ASL fingerspelling letter by letter.

02

Sign poses

Letter poses are loaded by the browser and played on the avatar.

03

Humanoid rig

VRM humanoid avatars allow the sign pose to drive the arm, hand, head, and finger rig.

Capabilities

Built for the next sign.

Use an avatar that you are licensed to use. VRM files are recommended for their standardized humanoid bones.

◈

ASL model

smart_gestures supplies the real internet ASL model for the sign-to-text path.

◇

Local VRM

The configured local VRM is served locally and is not uploaded to a third party.

✦

Browser demo

The browser supports .vrm humanoid avatars through Three.js and three-vrm.

Project notes

A clear starting point.

For a production-ready version, the project would expand the dataset and add a richer alphabet vocabulary, better word assembly, and full-body motion capture.

Current focus

The project is intentionally static-fingerspelling focused and matches the recommended MVP.

Current boundary

Fluent ASL grammar and word-level motion require a licensed motion/animation dataset.

Next direction

Expand the dataset and add a richer alphabet vocabulary, better word assembly, and full-body motion capture.
